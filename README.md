## Project Description
This repository contains all the exercises and projects completed during Week 6. During this week, I learned how to work with asynchronous JavaScript using Promises, async/await, and the Fetch API. I also learned how to fetch data from APIs, send POST requests, handle loading and errors, search and filter data, and build a Weather Dashboard application.

## Technologies Used
- HTML5
- CSS3
- JavaScript 
- Fetch API
- JSON
- JSONPlaceholder API
- OpenWeather API
- VS code
- Git & GitHub

## Features
- Fetch data from APIs using GET requests.
- Send data using POST requests.
- Display loading indicators while fetching data and fetched data dynamically on the webpage.
- Build a Weather Dashboard using the OpenWeather API.

## How to Run
1. Clone this repository.
2. Open the project in Visual Studio Code.
3. Open `index.html` using Live Server.
4. If running the Weather Dashboard, replace the API key with your own OpenWeather API key.
5. Test each exercise through your browser.

## Lessons Learned
- How Promises work and how they simplify asynchronous programming.
- How to use async/await to write cleaner asynchronous code.
- How to fetch data from REST APIs using the Fetch API.
- How to send POST requests.
- How to handle errors using try...catch and `response.ok`.
- How to update the DOM using fetched data.

## Challenges Faced
One challenge was understanding how asynchronous JavaScript works, especially when using Promises and async/await. I overcame this by practising each exercise and following the flow of asynchronous code step by step.

I also experienced some Git and GitHub issues while organising my project files, but I learned how to structure my folders and keep my repository organised.
